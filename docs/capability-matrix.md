# GAUGE: System Monitor — Device Capability Matrix

This matrix provides the authoritative 12-column platform feasibility audit across all 25 system telemetry features for Android 10 (API 29) through Android 15 (API 35).

---

## 1. Authority & Technical Principles

1. **Truthful Diagnostics**: GAUGE never mocks, estimates, or simulates telemetry values. If an API is restricted by Android SELinux policies or missing hardware fuel gauges, GAUGE discloses the limitation truthfully.
2. **Zero Snake-Oil**: In accordance with Google Play Developer Policies and `antislop.md`, GAUGE rejects "RAM cleaners", task killers, and fake cache wipers.

## 3. Summary of Feasibility Tiers

- **Fully Feasible Standard Features (16 items)**: System RAM, memory pressure, self-app memory, primary/secondary storage volume, battery current/voltage/temp, thermal throttling status, SoC and core counts, display metrics, sensors, network traffic counters, launcher app discovery, Room local history, SAF export, and local threshold alerts.
- **Feasible with User Authorization or OS Limits (4 items)**: App foreground usage history (`PACKAGE_USAGE_STATS`), package storage breakdown (`PACKAGE_USAGE_STATS`), battery cycle count (API 34+), and active CPU frequencies (chipset-dependent).
- **Strictly Infeasible / Snake-Oil Prohibited (5 items)**: Per-app process RAM table, arbitrary disk cleaning, per-app battery mAh attribution, system-wide total CPU % from `/proc/stat`, and task killer "End Task" buttons.
